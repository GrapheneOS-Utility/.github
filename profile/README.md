## What GrapheneOS Brings to Privacy-Focused Mobile Workflows

GrapheneOS is a mobile operating system based on the Android Open Source Project with a strong focus on privacy and security. The project develops changes intended to strengthen application isolation, permission controls, exploit mitigations, and other security boundaries.

Application sandboxing is a central part of the platform. GrapheneOS hardens the existing Android application sandbox and adds additional protections around system components and application execution.

Permission management provides additional control over application access. GrapheneOS includes controls for areas such as network access, sensors, storage scopes, and contacts, allowing supported permissions to be managed more precisely.

User profiles provide separated workspaces with their own applications and profile data. This can be useful when different groups of applications or activities need to remain separated from one another.

Privacy-oriented defaults are another important part of the platform. GrapheneOS does not include Google apps and services by default, while its compatibility layer allows Google Play components to operate as sandboxed applications when users choose to install them.

The platform also includes security-focused components. Auditor provides hardware-based verification and attestation capabilities, while Vanadium provides a hardened browser and WebView environment developed specifically for GrapheneOS.

Verified boot and exploit mitigations contribute additional security boundaries. GrapheneOS describes enhanced verified boot, hardened application runtime components, attack-surface reduction, and additional sandboxing improvements among its platform changes.

Network controls can provide more granular application-level management. The Network permission toggle can restrict an application's direct and indirect network access within its profile.

Encrypted backups are also part of the platform's broader utility. GrapheneOS documents encrypted backup support through integration with Seedvault, including local backup and supported storage-provider workflows.

Together, these components create a mobile environment where privacy controls, application isolation, security verification, and user-profile separation are treated as integrated parts of the operating system rather than separate utilities.
